## 一、要做什么（5 件）

### ① 一键启动 / 停止脚本（双击即可）
- `启动演示.command`：**生产模式**启动（后端 8020 → 前端 5180 → 等就绪 → 自动打开浏览器）

### ② 预置一个"跑完的"演示方案（关键省钱点）

### ③ 演示话术脚本（照念，5 分钟）
逐屏写清：**点哪里 → 说什么 → 哪句话必须说**（三条口径：示例数据·仿真实例 / AI 生成示意图（非实物照片） / 成本为估算值 / 打样为演示流程）。含"如果不成功就说这句"的兜底台词。

### ④ 断网 / 额度兜底
- **演示前检查清单**：Key 是否还在、余额是否够（DeepSeek + 火山方舟各留一点）、后端 health 是否正常

- **兜底二**：`IMAGE_PROVIDER=placeholder` 模式演示（标"占位图"，**不出图、零费用**）
- **兜底三**：万一后端起不来，直接用**已导出的 Word / Excel**（桌面已有一份）讲交付物

### ⑤ 彩排一遍并计时
- 从"双击启动"到"演示讲完"完整走一遍，记录实际耗时；截图留存作为证据包
