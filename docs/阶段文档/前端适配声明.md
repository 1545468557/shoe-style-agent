# 前端适配声明 · 鞋服智能设计 Agent（款式工场）

**日期**：2026-09-21　**阶段**：3 正式前端（第一版）

## 一、技术选择

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | **Next.js 15（App Router）+ React 19 + TypeScript** | 与同一仓库内已建成的法小智前端同栈，团队无需学新东西；有生产构建与类型检查可用 |
| 样式 | **纯 CSS（一份 `globals.css`）** | 不引入 UI 框架，避免"像后台模板"；设计师给稿后可直接落成 CSS |
| 端口 | **5180** | 8020=后端；8010/8011/8012/5174/5175 已被法小智占用，本项目不越界 |
| 与后端通信 | **浏览器直连后端 + 后端放行本机开发端口 CORS** | Next 的 `rewrites` 代理在本组合下实测不生效；直连确定且可验证 |
| 媒体地址 | `lib/api.ts` 的 `mediaUrl()` 把 `/assets`、`/files` 相对路径转绝对地址 | 后端返回相对路径，跨端口访问需要绝对地址 |

## 二、安全与口径

- 前端产物中**不含任何密钥**；`.env.local` 仅一行后端地址。密钥只存后端 `.env`（已 gitignore）。
- CORS **只放行本机开发端口**（localhost/127.0.0.1 的 5180 与 8020），**不使用 `*`**；上线时需改为正式域名。
- 页面强制显示口径标注：`示例数据 · 仿真实例`、`AI 生成示意图（非实物照片）`、成本标 `估算值`、打样标 `演示流程`。
- 界面不出现内部术语（不写"门1/门2/BOM/迭代器"）；按钮说人话（"就用这个方向""算用料和尺寸"）。

## 三、当前实现范围与暂缓

- **已实现**：五步工作台（企划→方向→面料→版型→用料导出）+ 点图放大 + 两方向并排对比 + 改版记录 + Word/Excel 导出 + 打样单与审批。
- **暂缓**：灵感板（moodboard）、PDF 导出、方案列表页（"我的设计"目前只有入口文案）、账号登录（按 D11 砍除）、工艺默认预选（**待产品经理确认是否让模型给"建议工艺"**，涉及一次额外模型调用）。
